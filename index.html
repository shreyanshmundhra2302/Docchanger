Quick colors (tap ✎ to change)
Type or paste text below. Select any text, then choose font / size / color and click "Apply to selection". Use "Import font" to load a font file you downloaded (e.g. from Google Fonts). Type a hex code directly, or tap a quick-color swatch (tap the small ✎ on a swatch to change what color it holds). "Save as PDF" opens your print dialog — choose "Save as PDF" as the destination.
