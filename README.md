# Simple Doc Editor

A single-page tool to type or paste text, change font (including Google Fonts),
size, and color, then save the result as a PDF.

## How to deploy on Render
1. Create a new GitHub repo and upload these files (index.html, README.md).
2. On Render: New -> Static Site -> connect this repo.
3. Build command: leave empty
4. Publish directory: . (just a dot, meaning the root folder)
5. Deploy. Render will give you a live URL.

## How to use
- Type directly in the page, or paste text (Ctrl+V).
- Select any text with your mouse/finger.
- Pick a font, size, and color from the toolbar, then click "Apply to selection".
- Click "Save as PDF" -> in the print dialog, choose "Save as PDF" as the destination.
